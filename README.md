# Song Maker AI
*A simple tool that uses AI to create songs in [chrome music lab's song maker](https://musiclab.chromeexperiments.com/Song-Maker/)*


# DISCLAIMER
**THIS PROJECT IS NOT MEANT TO GLORIFY AI IN CREATIVE FIELDS, AND MERELY SERVES AS AN EXPERIMENT FOR EDUCATIONAL PURPOSES ONLY**

## Usage
Download/clone the repo and create a file named `key.txt`  
Put your API key from [OpenRouter](https://openrouter.ai/workspaces/default/keys) inside of this file.

Run `pip install -r requirements.txt` to install dependencies.

Run the python script, then put the chrome window in fullscreen and refresh the page. Go into the song maker settings and put 'length' up to 16 bars.

Then, go back to your python terminal and press enter. Following this, input your song prompt and length. After some time the song will be done and it'll automatically place all the notes inside of Chrome Music Lab. You can then listen to it


## Extra customisation
If you want you can change the openrouter model, and play around with the prompt. You could probably get it to play around with different scales, starting notes and ranges!
